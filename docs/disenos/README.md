# Diseños de Urbanshop — Guía visual para frontend

Archivos PNG exportados de las maquetas. Se usan como referencia para las tareas de frontend en `TAREAS.md`.

## Archivos

| Archivo | Qué muestra |
|---|---|
| `urbanshop-marca-desktop.png` | Logo, paleta, tipografías y reglas de la marca. |
| `urbanshop-01-home-desktop.png` / `...-movil.png` | Home con ProductGrid en estilo de fundas de disco. |
| `urbanshop-02-producto-desktop.png` / `...-movil.png` | Detalle de producto con selector de variante y trama de stock. |
| `urbanshop-03-carrito-desktop.png` / `...-movil.png` | Carrito con regleta de pistas/importes alineados a la derecha. |
| `urbanshop-04-checkout-desktop.png` / `...-movil.png` | Checkout con formulario de envío y resumen de orden. |
| `urbanshop-05-confirmacion-desktop.png` / `...-movil.png` | Recibo troquelado + ruta de estados del pedido. |

## Identidad resumida

- **Mundo:** tienda de discos / crate-digging.
- **Paleta:** Papel `#F3EFE4`, Tinta `#1B1A17`, Rojo Prensa `#C43D2B`, Cara B `#2E6B67`.
- **Tipos:** Archivo (display y cuerpo), Martian Mono (catálogo, precios, labels).
- **Señas:** fundas cuadradas, números de catálogo, trama de hatch para stock, precios con línea de puntos, formas angulares.

Para implementación, ver `DESIGN.md` y `.impeccable/design.json` en la raíz del proyecto.

## Nota

Las maquetas HTML/CSS usadas para generar estas imágenes viven fuera del repo (`mockups/`) para no confundirse con el código de producción. Solo los PNG + `DESIGN.md` sirven como guía.
